## Full description
PixLite is a lightweight document and image toolkit designed for quick everyday file tasks.

Create PDF files from images, merge multiple images into one PDF, compress images, resize dimensions, scan documents, and generate QR codes from one clean interface.

Key features:
- Image to PDF
- Merge images into a single PDF
- Compress image files
- Resize image dimensions
- Document scanner
- QR code generator
- Local file history for files created with PixLite
- Light and dark themes
- English, Arabic, French and Spanish interface

Privacy-focused workflow:
PixLite processes selected documents and images on the device for its document features and does not upload your documents to PixLite-owned servers. Generated files remain on your device until you remove them. PixLite uses Google Mobile Ads, which may process advertising-related data according to Google policies and applicable consent requirements.

PixLite is built for fast, simple document work without unnecessary complexity.
